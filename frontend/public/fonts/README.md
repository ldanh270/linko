# Reference fonts

Extracted from user-supplied `docs/assests/chats.htm`, a SingleFile snapshot of the Chatvia Tailwind template (Themesbrand), saved 2026-10-24. Public Sans variable Latin subset (400–600) and Remix Icon webfont are retained to reproduce the supplied UI. Only the used icon mappings are included in CSS. Public Sans is SIL OFL; Remix Icon is Apache 2.0. Vietnamese glyphs absent from the embedded subset fall back to the existing Be Vietnam Pro font. No demo photos or message content are shipped as production fallbacks.
